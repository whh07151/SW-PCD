# AI 기반 학술 정보 검색 도구

자연어 질문을 기반으로 논문·리포트·기사 등 학술 자료를 검색하는 도구의 기획 및 설계 산출물 저장소입니다.

## 현재 상태

이 저장소에는 프로젝트 계획서, 주차 보고서, 상세 설계서와 발표 자료만 있습니다. Swift/Node.js 애플리케이션 소스, 의존성 선언, 실행 환경설정은 포함되어 있지 않으므로 현재 상태로는 빌드하거나 배포할 수 없습니다.

문서에 기술된 목표 기능은 다음과 같습니다.

- 자연어 질문 의도 분석
- 학술 자료 검색과 관련 결과 제공
- Swift·SwiftUI·UIKit 기반 클라이언트
- Node.js·MySQL 기반 서버

위 항목은 문서상의 설계이며, 이 저장소에서 동작이 검증된 구현 목록은 아닙니다.

## 산출물

- 최종 프로젝트 계획서
- 6~9주차 보고·발표 자료
- 소프트웨어 상세 설계서

PDF와 PowerPoint 파일은 원본 형식으로 보관합니다. 새 문서를 추가하거나 교체하면 GitHub Actions가 PDF 헤더·종료 표식과 PowerPoint ZIP 구조를 검사합니다.

## 문서 검증

Python 3.11 이상에서 별도 패키지 설치 없이 실행할 수 있습니다.

```bash
python3 scripts/validate_documents.py
```

이 검사는 파일 컨테이너가 손상되지 않았는지만 확인하며 문서 내용의 정확성, 개인정보 포함 여부, 외부 링크 유효성은 보증하지 않습니다.

## 구현을 시작하기 전 필요한 작업

1. 클라이언트와 서버 소스의 기준 브랜치 및 소유권을 확정합니다.
2. 재현 가능한 의존성 잠금파일과 로컬 실행 절차를 추가합니다.
3. 실제 API·DB 스키마와 문서의 설계가 일치하는지 검토합니다.
4. 테스트용 합성 데이터로 빌드·단위 테스트·통합 테스트 CI를 구성합니다.
5. API 키와 DB 인증정보는 저장소에 커밋하지 않고 `.env.example`에는 변수 이름만 기록합니다.
6. 개인정보·저작권·학술 데이터 이용 조건을 검토한 뒤 배포 대상을 결정합니다.

구현 소스와 검증 가능한 실행 절차가 추가되기 전까지 이 저장소는 배포 가능한 애플리케이션이 아니라 설계 문서 아카이브로 취급합니다.
